## Part A
```
python -I -B forge_sol_S47_verify_netonly_tree_20261027.py --lock <lock tree | AUTOLOCK dir> --cand <tree | AUTOLOCK dir> --net-md5 <md5> [--gate-json <gate record>] [--out v.json]
```
Hashes every file under `include/` and `src/` (`--scope`) raw and after CRLF->LF; files equal after normalisation are listed
as `crlf_only_ignored`. PASS needs: no file only on one side, no difference outside `src/nnue_weights.inc`, the net different
from the lock and its md5 equal to `--net-md5` (raw bytes; an LF-only match is reported as `lf`). An AUTOLOCK dir is read
through its `source/` tree and its LOCK.json (the lock's own net md5 is cross-checked). With `--gate-json`, a CAP-LATE Z
re-gate (`ag_rebase_of` set) whose tree is not net-only FAILs with "Z-1 (CAP-LATE Z): ... must never be promoted".

## Part B
```
python -I -B forge_sol_S47_autolock_audit_20261027.py --old-lock <dir> --new-lock <AUTOLOCK_n_tag dir> --old-hashes <list> \
  --gate-result R.md --gate-run-info RUN_INFO.json --gate-record rec.json --confirm-result ... --confirm-run-info ... --confirm-record ... \
  --net-md5 <gated net md5> [--old-ref BENCH_REF.txt|PREBENCH.txt] [--old-uci] [--pin-allow allow.json] [--cr-dir dir] --out-md p.md --out-json p.json
```
Checks A1-A11 (see the tool header): every row is PASS, FAIL or MISSING (A11 INFO). Overall FAIL (exit 1) if any FAIL,
INCOMPLETE (exit 3) if any MISSING, else ALL_CHECKS_PASS (exit 0). Even ALL_CHECKS_PASS is evidence, not a CR PASS:
`grants_cr_approval` is always false and no CR_PASS file is ever written. The old lock's bench / uci / pins come from the
old lock's own files (BENCH_REF.txt or the gate's PREBENCH 'base dNN' lines via `--old-ref`, UCI_OPTIONS.txt, pins/);
the expected new bench is the gate's `prebench.cand_off`; perft defaults to 4865609 / 193690690 (`--perft-expect`).
