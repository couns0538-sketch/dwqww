| idea | source | licence | how it is used here |
|---|---|---|---|
| lockless hashing: store the key XOR the data so that a reader can detect a mixed pair | R. Hyatt, T. Mann, "A lock-less transposition table implementation for parallel search chess engines" (ICGA Journal 2002), described in the literature | paper (idea) | **idea only**. The encoding here is this job's own: a 32-bit tag XOR a digest of the data word without the generation bits, an exact bijection with P's 16-byte TTEntry, and digest(0) = 0 so zeroed memory is the empty entry. The digest was `mix32(move, D)` up to `0599271` and is `tag32(D)` since enc2 (next row) |
| the digest `tag32(D) = high32(D' * 0x9E3779B97F4A7C15 mod 2^64)`: multiply-shift hashing with the golden-ratio multiplier | M. Dietzfelbinger, T. Hagerup, J. Katajainen, M. Penttonen, "A reliable randomized algorithm for the closest-pair problem" (J. Algorithms 25, 1997): the multiply-shift family and its 2^(1-l) collision bound. D. E. Knuth, TAOCP vol. 3, §6.4: multiplicative ("Fibonacci") hashing | papers / textbook (idea) | one multiply instead of three. The exact collision rule for this fixed multiplier, the census tool and the F47 observation are this job's own (SPEC 3.3, BENCH §9); the fable bug hunt derived F47 independently |
| `std::bit_cast` decode with layout static_asserts | ISO C++20 (`<bit>`) | standard | decode is one reinterpretation of the two words, guarded by endianness / offset asserts and a field-by-field reference test |
| why seqlock payloads must be atomic under the C++ memory model | H.-J. Boehm, "Can seqlocks get along with programming language memory models?" (MSPC 2012) | paper (idea) | the reason no seqlock with plain payload is used; every shared word is accessed atomically |
| `std::atomic_ref` over plain storage, relaxed loads/stores/CAS | ISO C++20 ([atomics.ref.generic]) | standard | storage stays plain `std::uint64_t` (value-initialisable and clearable while quiescent); all concurrent accesses go through atomic_ref |
| per-thread counter on its own cache line to avoid false sharing | general practice (cache-coherence basics) | — | applied only where layout_probe measured a cross-thread written+read line (`Worker::nodes_`) |
| striped-lock TT, opaque TTProbe handle with epoch, ExclusiveLease, `FORGE_SPD_TT_NOTLS` owned path | this repository (lock d4f4312; trial_w6.patch) | own code | kept unchanged as the OFF path; the lockless bodies mirror probe_body / store_body decision by decision |
| tests: torn-tuple detectors | this repository (`tests/tt_coherence_tests.cpp`) | own code | model for the new contention fixture; the new tests are own code |
