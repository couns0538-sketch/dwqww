(b) The delta criterion is exact. With x = D2'*M and y = delta*M (mod 2^64), D1'*M = x + y; writing x = xh*2^32 + xl, y = yh*2^32 + yl: high32(x + y) = (xh + yh + c) mod 2^32 with carry c = [xl + yl >= 2^32]. Equality with xh <=> (yh == 0 and c == 0) or (yh == 2^32-1 and c == 1). yh == 0: c == 0 is achievable (xl = 0), so "can collide". yh == 2^32-1: c == 1 needs xl >= 2^32 - yl, achievable iff yl >= 1. Hence can_collide(delta) == (yh == 0) || (yh == 0xFFFFFFFF && yl != 0) is exactly "there exists D2' such that the tags collide" (xl ranges over all 2^32 values because M is odd and the low 32 bits of D2' are free). It is symmetric in the sign of delta (y -> -y swaps the two cases), so the test's +-2^bit checks are redundant but harmless. The per-delta collision probability over a uniform xl is c(delta) = 1 - yl/2^32 (yh == 0 case) or yl/2^32 (yh == -1 case), i.e. c(delta) = max(0, 1 - |delta*M mod 2^64|/2^32) with |.| the distance to 0 mod 2^64.
