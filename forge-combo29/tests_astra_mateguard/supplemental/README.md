# Supplemental tests — native validation passed

`seeded_search_regression.cpp` is a standalone test translation unit for the gate=1 audited tree. It uses the existing `forge::SearcherTestProbe` friendship; it introduces no engine hook. The successful compile uses the baseline flags.make ABI/feature settings plus `FORGE_MATE_ALPHA_GUARD=1` for search.cpp and this test. Unchanged baseline bitboard, board, book, eval, eval_params, and nnue objects are reused; the gate adds no layout change in these units. UCI/main and other test units are omitted. Exact argv and hashes are retained in the native logs.

The tests execute real non-root `Worker::search`, not a copied pruning formula. The internal KRK witness preserves the recorded eight-move board history, logical ply 8, requested depth 5, alpha 31982/beta 31983, raw eval 521, d3d2 first, and d1c1 second. The test independently checks the five-ply continuation, including Black's unique replies and final checkmate without repetition.

Move ordering, static-evaluation context, histories, and child TT responses are controlled synthetic state. Each direct child receives a deep Exact seed; only the target returns the marker score. Consequently the returned marker proves that the real search reached that move. This is deliberately an artificial reachability test, not a certification of those seeded Exact bounds or a reproduction of the complete original run. In the capture/SEE fixtures marker scores carry no mate-soundness claim. Parent `ValueNone` seed supplies only ordering and ordinary raw eval, avoiding a parent TT cutoff and IIR depth loss.

The independent capture fixture is Rxd5 against an undefended pawn, after a first TT quiet, with `CaptureFutilityBase=100`. Controls exercise ordinary-alpha futility under both option values; LMP, negative history, quiet SEE, and capture SEE remain active under the narrow guard. For each latter control, the broad SoundArmMateAlpha arm and a single targeted selectivity relaxation establish that the target is otherwise reachable. Other SoundMatePruning arms are forced off. The two SEE preconditions are checked through `Board::see_ge`, and TT seeds are checked for eviction.

All drafted controls passed on the authorized native run; see VALIDATION.md and 04-run.stdout.txt. If a later control fails, inspect the actual result and ordering; do not weaken it into a formula-only test. The full original-root semantic trace and ten repeat acceptance checks remain required, particularly the PV frame that starts with ordinary alpha and raises it to a mate score. These drafts cover only a preexisting mate-alpha window, not that dynamic transition. Default undefined/0 builds, UCI advertisement/default and hash invalidation belong in the separate protocol tests.
