The ordered switches.tsv contains every experimental PC override, once per option. The combined control applies all of them in order. Each single-arm test applies only its own line. Other search mechanisms and inactive options

• Alpha-beta and principal variation search have no UCI disable value. Main beta cutoff at 2319 is `if (score >= beta)` with break at 2321. PVS zero-window and possible full-window re-search appear at 2296–2300. Alpha-beta bounds, move order, TT state and depth reductions interact. The full-depth re-search of a reduced move requires `score > alpha && reduced_depth < new_depth` (2279).
• Main/qsearch TT cutoffs have no global off. Lines 1847–1851 and 1653–1657 accept `tt_bound == BoundExact` or a lower/upper bound passing `tt_score >= beta` / `tt_score <= alpha`. `Clear Hash` clears stored entries at that moment. The search immediately starts repopulating them. TtPruneV2 false does not bypass these returns.
• Main LMR has no UCI off. Eligibility is `depth >= 2` and `move_count > 1 + (root_node ? 1 : 0)` (2254–2256). A root move can be reduced even though shallow move-loop pruning excludes the root (2096). Beyond the four table knobs (302–306), the engine adjusts r for TT-PV, improving, cut nodes, TT captures, checks, history and other conditions (2257–2275). It tests a reduced-depth null window before deciding on a full-depth re-search (2275–2287). LmrHistoryDivisor [1000,30000] scales a signed adjustment, with no globally least-reducing direction. LmrSignedCorrection, LmrLateParentRelief, LmrDeeperShallower and HindsightDepth are false in PC20. The hindsight-adjustment guard is `if (tune::HindsightDepth)` (1820); `proposed = depth - 1` at 1834 is already inactive. No UCI value removes ordinary move ordering. HistRework changes scores/history; CorrHistV2 and NonPawnCorrection affect the static evaluation that feeds pruning (1298–1315, 1450). They are inputs rather than off-switches for a specific pruning step.
• Quiescence is entered on `if (depth <= 0) return qsearch_child(...)` (1762). There is no UCI override for that boundary, stand pat `if (best_score >= beta)` (1676), or quiescent alpha-beta cutoff `if (score >= beta) break;` (1738). The quiescence move picker rejects a quiet non-promotion TT move outside check (666–668), enters QsGenerate/QsCaptures outside check (670–671, 751–761), and handles evasions separately when in check (670, 763–773). A quiet non-capturing mate threat can be absent from this horizon.
• Ordinary check extension is positive, `depth >= tune::CheckExtensionDepth` and a safe check at 2218–2220. Its threshold [1,30] defers that extension. It is not a pruning or reduction switch. SingularDepth separately controls the verification family including negative extensions. The PC r15 double-extension test has hard-coded margin 24 and inherited limit 6 at 2208 (no separate UCI knob in PC).
• QuietExtinction false is already off (`tune::QuietExtinction && !root_node`, 2060). The optional tight futility test (2181–2186) and closing of the later quiet tail (2327–2330) therefore stay inactive. This is distinct from the normal LMP and futility skip_quiets paths. AspFailHighReduce [0,1] is already zero (`tune::AspFailHighReduce != 0`, 2766–2767). Normal aspiration windows remain in use (`depth >= 4`, 2748). AspirationDelta [4,200] changes window size without disabling the mechanism.
• NullThreatVerify and NullSeeVeto are false in PC20; enabling either would gate particular null-move opportunities or require verification (1944–1948, 1968–1989). Neither disables null-move pruning globally. SoundMatePruning and MateAlphaGuard apply at different sites: the first exempts a whole move-loop block in three cases (2092–2097), the second contributes only to the two futility branch predicates (2134, 2159).
• Non-root mate-distance pruning bounds alpha and beta and may return when `alpha >= beta` (1777–1783). No general UCI off. Rule-draw and MaxPly returns are at 1627–1628 and 1778–1779. `go mate` and fixed-depth `go depth` select distinct search modes. This experiment uses the latter throughout. The structural maximum-ply and legal/terminal checks are retained.

PCA-only extra arms
On the PCA build, after PC20, send RfpTtGuard 1 or RfpNoTtPv 1 separately. Both spin ranges are [0,1] with default 0. From PCA src/search.cpp:1955–1962, the guards `!(tune::RfpNoTtPv != 0 && ss->tt_pv)` and `!(tune::RfpTtGuard != 0 && !tt_move.is_none() && !tt_move.is_capture())` protect TT-PV and quiet TT-move nodes respectively. RFP on other qualifying nodes stays active. Neither UCI setting is present in the PC control executable.
