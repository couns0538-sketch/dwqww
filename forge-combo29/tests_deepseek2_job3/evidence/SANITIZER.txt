Sanitizer build and runs (job 3, proof e)

Build of the fully patched tree (/tmp/ds2/pall), private copy:
  cmake -DCMAKE_BUILD_TYPE=RelWithDebInfo -DFORGE_MARCH=native \
        -DCMAKE_CXX_FLAGS="-DFORGE_NNUE_V3=1 -fsanitize=address,undefined -fno-omit-frame-pointer -g" \
        -DCMAKE_EXE_LINKER_FLAGS="-fsanitize=address,undefined"
  g++ 13.3.0

Environment for every run:
  ASAN_OPTIONS=detect_leaks=0   (the engine is stopped with `quit` mid-teardown)
  UBSAN_OPTIONS=print_stacktrace=1

Planted-fault control, compiled with the same flags and run FIRST:
  sanitizer_planted_fault.cpp -> "runtime error: store to address ... with insufficient
  space for an object of type 'int'" (UBSan) and "ERROR: AddressSanitizer:
  heap-buffer-overflow" WRITE of size 4 (ASan).  Both reported, so the harness sees faults.
