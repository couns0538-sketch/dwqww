The plain engine already takes one ply of reduction off the first four replies when the
parent move's arrival index is at least 7, behind LmrLateParentRelief, default false.
Those three numbers were fixed. They are now spin options IdeaS35_Index default 7,
IdeaS35_Replies default 4, IdeaS35_Plies default 1. With IdeaS35 false and those
defaults, LmrLateParentRelief true still does today's subtraction of one ply, and both
switches false never enters the block.

What IdeaS35 adds, from IDEAS.md S35, which the engine did not do: a second ply of
relief on the first reply only, when the parent try is far past the late gate. "Two
dozen tries" in that note is the far line, so IdeaS35_Far default 24. The second ply
is subtracted only when IdeaS35 is true. Replies after IdeaS35_Replies keep the normal
reduction. reduced_depth is still clamped to new_depth, so the relief cannot extend.

Far is an absolute arrival index, not Index plus a margin, so the default pair (7, 24)
matches the old gate plus the two-dozen line. A user who sets Far at or below Index
gives every late parent's first reply the extra ply. That is a tuning choice, not the default.
