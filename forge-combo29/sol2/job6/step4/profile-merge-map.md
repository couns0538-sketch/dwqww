The `fill_pseudo_legal<GenMode 0>` instantiation, candidate residual `fill_pseudo_legal<GenMode 1/2>` samples and separately named callbacks or library functions are retained under their emitted names. The direct function mapping leaves the subsystem classifier unchanged. It still uses the Job 3 inline-frame rules and source-path attribution, so moving work across functions can change labels near category boundaries.

For each clean run, a subsystem's estimated CPU seconds are `subsystem_samples / all_samples × engine_cpu_seconds`, using the engine CPU receipt from that same run. The comparison table averages those per-run estimates across the three runs of each build. Pooled percentage columns use total subsystem samples divided by total samples for the build. Unresolved samples remain in the denominator. The inputs and per-run estimates are retained separately. The trace gate uses the pinned PC20, Threads 1, Hash 16 MiB, net768 and `go softnodes 2000` workload of 8,612 searches and 29,333,343 last-iteration nodes with trace `5c705841c3ea17b4`.
