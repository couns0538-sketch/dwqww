### H33_design.txt
H33 opens kF src/search.cpp1819-1829. The newly cached material-count index uses validity bit8; surrounding nonpawn-cache, material-mix and NNUE metadata lines are context, not all proved by this counter.
One use per record_move after child->corr_valid assignment and before NNUE-disabled early return. Independently copy square-array board and apply the move with existing piece_reference::after, handling destination capture, EP removed pawn, promotion replacement and castling rook relocation. Count White/Black Pawn..Queen from square arrays before/after. Expected child bit8valid = parent bit8valid AND identical countvectors. Compare actual child bit8 validity. For actual-valid child only, compare index with freshly hashed postmove square counts using original material_key constants/mask. Invalid payload intentionally unspecified and ignored.
This checks transition even if no later correction-history consumer uses the child. It differs from H36's selected consumer index check. Reference makes no Board move, mutates no actual cache, and invokes no old counted hooks. Shares piece_reference copy/after and move semantics with earlier independent diagnostics; not a standalone chess-law oracle. Counter covers only material-index valid bit and valid payload, not nonpawn-index/material-mix/metadata transitions or arbitrary malformed moves.
Classes White/Black, parent_valid/invalid, count_changed/unchanged, child_valid/invalid independently partition uses. Moveclass partition priority EP, then promotion (including promotion capture), then ordinary capture, else quiet (including castle). Classes derive flags, while validity reference derives actual square countvector changes.
WRONG15 flips only private expected-valid Boolean on White-to-move transitions. This affects one reachable class without touching real child cache or fresh index. Control must show White uses strict subset. Old25 counts and strict canonical final-info values except time/nps must remain exact per search. No reference native test was run before prediction.
