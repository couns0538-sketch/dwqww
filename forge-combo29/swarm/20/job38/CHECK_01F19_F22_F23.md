## Board 1 — `8/8/8/8/2K4Q/8/8/1k6 w - - 100 1` (S-F19's, which S-F23 withdrew)

python-chess: valid; `can_claim_fifty_moves()` **True**; mates in exactly 3 plies exist (5 of them, e.g.
`c4c3 b1c1 h4h1`); **but no mating line's first ply is a pawn move or a capture**, so nothing resets the counter.

| build | `go depth 5`, 3 runs |
|---|---|
| base + S14 | `h4e1` / **cp 0** / **0 nodes** ×3 |
| PC r15 + PC20 | `h4e1` / **cp 0** / **135 nodes** ×3 |

**My reading matches S-F23, not S-F19:** with no counter-resetting mate available and the fifty-move claim already
available at 100, `cp 0` is defensible chess. The base tree reaches it by *not searching* (0 nodes), the PC build by
*searching and concluding it* (135 nodes). Seat 01 withdrew the claim themselves; this confirms the withdrawal is
right, and it gives the distinction that matters: **0 nodes = shortcut, 135 nodes = a searched draw score.**

## Board 2 — `8/3K4/7P/8/8/7k/8/6Q1 w - - 100 1` (S-F22's discriminating case)

python-chess: valid; no mate in 1; the pawn on h6 makes a counter-resetting first move available.

| build | `go depth 5`, 3 runs |
|---|---|

the base tree's root shortcut can turn a win into a draw.

## What this adds beyond the two seats
- **The node count separates "shortcut" from "correct draw"**: base 0 nodes on board 1 is not wrong about the
  assessment but is wrong about the *method*; PC 135 nodes on the same board is a searched conclusion. A checker
  that compares only scores would call these two identical.
- Both boards reproduce the base tree's collapse identically at `Threads 1`, so seat 01's chain was not thread noise.
- Seat 01's own withdrawal (S-F23) is correct, and the discriminating test is theirs (S-F22), not mine.
