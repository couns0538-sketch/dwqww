PRECISE STATEMENT for a match harness:
  `go nodes N` means 'finish the iteration that crosses N, then stop'. The number printed on
  the last `info depth` line is the true total of the COMPLETED iterations and can be trusted
  as such; the nodes spent inside the aborted iteration are NOT printed. So the actual spend
  lies in [reported, N], the reported figure UNDERSTATES cost by up to N - reported, and a
  harness that reads the last info line gets an honest but conservative count.
  (Unlike softnodes there is no `info string softnodes nodes` total, so for `go nodes` the
  aborted iteration's nodes are invisible; for softnodes the total IS reported.)
