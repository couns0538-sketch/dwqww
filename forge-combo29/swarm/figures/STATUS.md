is a presence test** — "the file contains the number" is not accepted, because a file containing a
number is not a derivation.

## Reproducing

```bash
# a worktree at the audit base
git worktree add /tmp/base 6b98f217

# build (the default clang header path is broken in this image)
cd /tmp/base/forge-combo29 && mkdir -p build && cd build
LIBRARY_PATH=/usr/lib/gcc/x86_64-linux-gnu/13 \
  cmake -DCMAKE_CXX_COMPILER=/usr/bin/g++ -DFORGE_PORTABLE=ON \
        -DFORGE_MARCH=x86-64-v3 .. && make -j4
printf 'uci\nsetoption name Hash value 16\nsetoption name Threads value 1\nisready\nbench 11\nquit\n' \
  | ./forge | tail -1        # must print nodes 312866

# the ledger
cd forge-combo29/swarm/figures
python3 scripts/figures.py --forge /tmp/base/forge-combo29/build/forge \
    --seats <dir with NN/ seat trees> --base /tmp/base --repo . \
    --json evidence/ledger.json
```

`--seats` expects one directory per seat (`01/`, `19/`, …), each containing that seat's
`forge-combo29/swarm/NN/` tree; the resolver tolerates one extra nesting level, because the
extracted trees have it and a missing path must not read as "the report has no evidence".
