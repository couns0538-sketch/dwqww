# PREDICTION — does S-F35 GENERALISE? Full-canonicalisation on 60 positions

S-F35 concluded the colour asymmetry is completely explained by move-generation order, on the evidence of **5
positions × 3 depths = 15 cases, all equal**. My own STANDING CAUTION habit 3 says a small sample is not a
property, so the "completely" in S-F35 is exactly the kind of word that needs a larger N before it stands.

Method: the S-F35 build (all five generation sites + root list canonicalised) against the base PC r15 build, on
**60 G positions** at depths 1 and 2 = 120 cases each build. PC20 options, Threads 1, Hash 16, cold per search.

P1. The full-canonical build is equal on at least 115 of 120 cases (>= 96 %). Kills it: under 108 (90 %), which
    would mean my "15 of 15" was a friendly sample and S-F35's word "completely" must be withdrawn.
P2. The BASE build is equal on a small minority at these depths — predicted under 40 of 120 — so the comparison is
    meaningful rather than both-equal-by-accident. Kills it: base above 80 of 120, which would leave little room
    for the fix to demonstrate anything.
P3. Every case where the full-canonical build is NOT equal is also unequal on the base build (i.e. the fix never
    BREAKS a case that was already fine). Kills it: any case the fix makes worse.
P4. The depth-1 cases are equal more often than the depth-2 cases on the full-canonical build, if a residue exists
    at all, because deeper search reaches more nodes (including more evasion nodes). Kills it: no difference,
    which would be consistent with a complete fix at both depths.
