## THE CONTROL — a non-binding budget must give a LARGER count

| budget | largest reported node count (first position) |
|---|---|
| 5000 | 3,616 |
| 20000 | 12,500 |
| 50000 | 41,353 |
| 500000 | 456,585 |

| question | answer |
|---|---|
| the budget CHANGES the node count (control) | **YES** |
| deterministic across 5 fresh processes | **8 of 8** |
| reported count never exceeds the budget | **8 of 8** |

**CONFIRMS**: `go nodes N` is deterministic across five fresh processes on every cell, and the reported node
count never exceeded N — while a larger budget reliably produced a larger count, so the cap is real and not
an ignored parameter.
