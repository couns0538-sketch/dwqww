## The claim, tested

| question | answer |
|---|---|
| bestmove identical across all five Hash sizes | **YES** (c3b5) |
| hashfull varies with size (the pressure) | **450, 65, 17, 1, 0** |
| node count varies with size | **YES — 69,686, 73,610** |

**CONFIRMS**: the answer does not change across Hash 1..2048 MB while hashfull does, so a TT resize changes
the pressure and not the choice. Node counts: see the row above — if they are identical, the search is
bit-identical; if they differ, the search changed but not the choice, which is the weaker statement and I say which.
