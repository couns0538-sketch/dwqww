# REPORT — seat 03, area 3, job 2: 500 special positions, perft 1..4 vs python-chess

**What was asked.** Find 500 special positions by filtering R and G with python-chess — castling with an attacked
transit square (A), an en-passant capture that would expose the king (B), a capture-promotion with check (C),
double check (D), a pinned piece that can capture its pinner (E) — and run perft 1..4 on each, engine vs
python-chess.

**The answer.** All differences are 0: 314 positions tested, 0 differing (position, depth) pairs at depths 1..4 and
0 root-move disagreements. The position count is 314, not 500, because classes B and D are nearly absent from R and
G (see the class sizes) — I did not pad the set to hit a number.

**How sure.** Sure about the 314 positions measured (machine join of two committed JSON files, plus a move-set
comparison). Not sure that these classes are representative of what a real game produces — a bare-king position
that only exists in my constructor is legal but vanishingly rare.

## A correction I must record

My first version of the class-B test computed the double-pushed pawn's square as `ep + 8` for White instead of
`ep - 8`; it found 0 class-B positions in R (45,000 positions!), 0 in G, and 0 in 6,000 random games. Those zeros
were my bug, not the engine's behaviour. After fixing it (job2/ep_common.py, with a known-answer self-test that
prints `pass: True`), a 6,000-game hunt found 14 real class-B positions, and the constructor built 320.

## What I am NOT sure about

- Whether the constructed class-B positions (`4k3/8/8/r2Pp2K/8/8/8/8 w - e6 0 1` and variants) exercise the same
  code path as the 14 real ones. Both agree with python-chess, so the code path at least answers correctly; but
  the constructed ones are not game-reachable, so an engine that special-cased "unreachable" could hide there.
- `ep_divide.py` reads `go perft 1` divide lines textually; a move printed without a count would be missed.
  Checked: the engine prints `move: count` for every root move (see ep_divide.txt.raw).
