## Derived rule

With the root at clock H, a mate whose MATING MOVE is at ply p (root = ply 0)
is found iff `p <= 100 - H`. Otherwise the search hits a node at clock >= 100
that is not checkmate, `is_draw` returns true (search.cpp:1304) and the subtree
returns 0 before the mate is reached.

Equivalently: the position is missed iff `H > 100 - p`.

## The finding

The band is NOT "halfmove 98-99". It is `H > 100 - p`, i.e. it starts three
plausible clocks earlier for a mate in two and five earlier for a mate in three.
A repair written against the reported board (mate in one, H=99) fixes exactly one
cell: one mate length, one clock. Measured, both named patches do exactly that --
they do not move the boundary at all (job2/PATCH_TEST.md).

Total pairs measured across both mate lengths: 80, predictions matched 80/80,
misses 32/32.
