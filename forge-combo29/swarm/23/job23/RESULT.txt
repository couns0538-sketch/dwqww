====================================================================================
23-F58 showed the base answering a naturally reached third occurrence in 0 nodes with a different move from the PC.
Both scores were cp 0, so the question was whether the MOVE is worse even though the position is drawn. It is.

| query | score |
|---|---|
| unrestricted depth 16 | cp 0 (bestmove b6b4) |
| **only e6e5 — the base's unsearched move** | **cp -805** |
| only b6b4 — the PC's searched move | cp 0 |

So the move the base picked **without searching loses about eight pawns of evaluation** — it hangs a piece — while the
PC's move keeps the position level. The score both engines report (cp 0) hides this completely: the defect is not
merely "a different move", it is "a losing move chosen with no analysis".

VERDICT: all four predictions held (P1 the base's move is >= 20 cp worse — it is 805; P2 both further games reached

The defect is therefore a REAL COST on a position that arises in normal self-play: a losing move, chosen instantly,
on a board the match program would otherwise have ended the game at.

THE HONEST COUNTERWEIGHT, which I will not drop: in a real match the game ENDS at the third occurrence, so this
position is never searched and this losing move is never played. The cost lands on analysis, other GUIs and human
play — where it is a losing move rather than a cosmetic difference.
