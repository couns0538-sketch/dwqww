SECOND BOARD VERIFIED (8/8/7Q/8/8/6k1/K7/R7 w - - 0 1), same pattern as S-F27:
   go nodes 20000  -> mate 7,  10-ply PV, needs 13, checkmate=FALSE  <- WRONG
   go nodes 50000  -> mate 6,  11-ply PV, needs 11, checkmate=TRUE   <- correct
   go nodes 250000 -> mate 4,   7-ply PV, needs  7, checkmate=TRUE   <- correct
   go depth 12     -> mate 4,   7-ply PV, needs  7, checkmate=TRUE   <- correct
So at 20000 the engine under-reports the mate distance AND prints a truncated PV; by 50000 it has converged
(mate 6) and by 250000 it reaches the true mate 4.

RATE: 2 of 14 mate scores at `go nodes 20000` have a non-mate PV (14.3%), against 0 of 17 at `go depth 12`
on the same 41 boards. That is a measured rate on boards where mates are frequent, and a clean control, so it
is a real number - unlike the middlegame survey (S-C8) which was vacuous.
CAVEAT: 41 boards, all bare-material endgames (KQ/KR/QQ/RR vs K plus my S-F1 board), so this is the rate for
ENDGAME boards; middlegames at 20k nodes rarely produce mate scores at all, so the practical exposure in the
owner's matches depends on how often a 20000-node search lands mid-iteration on a mate-producing position.
