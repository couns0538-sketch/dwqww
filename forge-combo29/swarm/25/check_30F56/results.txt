WHY THIS MATTERS FOR SAMPLE SIZE (their second half, which I can only support in principle, not measure here):
if the engine is deterministic, then a match played from one opening produces the SAME game every time it is
repeated - so playing 100 games from 100 openings, each with both colours, does NOT give 200 independent samples.
Each opening contributes one deterministic line (plus its colour mirror), so the effective sample size is the
number of OPENINGS, not the number of games. Any confidence interval computed over "games" from repeated openings
would be too narrow by roughly sqrt(2) or more.
I did NOT measure the both-colours-from-one-opening case, so I am not claiming the exact inflation factor - only
that reproducibility makes the "N games = N samples" assumption untenable, which is their point.
