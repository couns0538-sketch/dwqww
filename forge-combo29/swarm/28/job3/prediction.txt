# PREDICTION — S28 job 3 (AREA 8, THE CLOCK): movestogo

Committed and pushed ALONE before the first measuring command of this job. Never edited afterwards.

Job 3 asks: `movestogo 1, 2, 40` with `wtime 1000`: how much of the time is used.

`include/forge/clock_plan.hpp:36-42`:
    if (moves_to_go > 0) { mtg = min(moves_to_go, 50);
        soft = available / (mtg + 1) + increment * 3 / 4;
        hard = min(available * 4 / 5, soft * 4); }
with available = wtime - 10 = 990 here, and increment 0 (wtime 1000 asked without winc).
So the code predicts: movestogo 1 -> soft 495, hard 792; movestogo 2 -> soft 330, hard 792;
movestogo 40 -> soft 24, hard 96.

Reasoning: the soft limit is where the search tries to stop; an unstable iteration can run to the hard
limit. With 12 positions per cell the median should sit near soft and the largest near hard. The clamp
at 50 (`moves_to_go < 50 ? moves_to_go : 50`) means movestogo 50 and 51 must plan the same numbers, so
their measured times should agree within noise.
