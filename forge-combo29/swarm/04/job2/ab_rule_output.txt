== what one run per arm can and cannot tell you ==
A single Threads-4 run can differ from the truth by up to 48 cp (worst measured).
So an A/B of ONE run per arm cannot resolve an effect smaller than about 48 cp,
and even then only by luck. Effects below ~48 cp need the repetitions above.
