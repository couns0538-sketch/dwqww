## Revisions after CI

SonarCloud failed the first push. Every finding survived re-verification; the fixes were
substantive:

- **The scripts hardcoded `/tmp/asp` paths**, so nobody else could run them. Now
  `ASP_BUILD_ROOT` / `ASP_EVIDENCE` with defaults relative to the folder, plus
  `scripts/asp_paths.py` carrying the per-build macro sets. All evidence was regenerated by
  the shipped code and reproduces byte-for-byte.
- **The fault control was reported as 3/8**, which reads like a detector miss rate. 8 was
  the wrong denominator: the planted defect needs a fail-high on the *last* root iteration,
  which most positions do not have. Widened to the first 40 positions and now reported as
  **detected/fired = 6/6** with `rows_tried` kept alongside so the denominator is explicit.
- Hardened `Engine` (rejects a non-executable path), constrained `gen_mates.py`'s output
  path to the evidence directory, replaced a backtracking regex, and fixed a no-op
  conditional in `measure_mate.py`.
