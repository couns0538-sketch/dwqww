=== B. MECHANISM, FROM SOURCE (src/search.cpp) ===
  `mate_moves_ > 0` does NOT merely set a depth. It:
    * NARROWS THE WINDOW to [mated_in(ply), mate_in(ply+1)] and returns alpha if it empties
      (search.cpp:1431-1435);
    * DISABLES THE TT CUTOFF unless alpha/beta are already mate scores (1452);
    * DISABLES null-move / reverse-futility (1493, 1639);
    * DISABLES IIR (1784), quiet extinction (1805), the sound-mate case (1841),
      singular extensions (1929), and check extensions (1955).
  So `mate_moves_ > 0` is a DIFFERENT SEARCH, not a depth bound with extras.

=== C. REPEATABILITY AND COST, one board (r2qkbnr/pp2pppp/2npb3/2p5/...), fresh process each ===
  command          bestmove  depth  score        nodes
  go depth 3       e2e3      3      cp -52       186
  go mate 2        e2e3      3      cp -52       1740       <- 9.4x the nodes for the same answer
  go depth 7       d4c5      7      cp -33       3411
  go mate 4        e2e3      7      cp -36       556387     <- 163x nodes AND A DIFFERENT MOVE
  (each pair repeated: bit-identical, so this is deterministic, not noise)

CONCLUSION: a corpus labelled under `go mate N` is labelled by a search that would have:
  - disabled seven heuristics and the TT cutoff,
  - cost up to 163x more nodes for the same depth,
  - and returned a different bestmove in roughly half the positions tested.
The labels are not "depth 2N-1 labels". They are labels from a mate-hunting search, and if the
owner ever mixed them with `go depth` labels the two are not comparable.
