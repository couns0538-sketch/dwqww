=== THE SINGLE MECHANISM ===
  Every malformed-value command lands on the SAME result: [(5, 1001, 0.0), (1, 26, 0.0), (8, 4099, 0.0)]
  depth 5 / 1001 nodes / 0.0 s - i.e. an unparseable value is replaced by a default
  and the search runs a short default search with NO message.

  An unknown TOKEN is different: it is discarded and the well-formed search proceeds
  normally (go depth 8 zzzz 3 == go depth 8: 4099 nodes).
  'go depth 0' is a THIRD behaviour: clamp(0,1,64)=1, a legal one-ply search.
