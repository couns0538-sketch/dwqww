Seat 17 reports 84/105 nodes for the PC build on this board; that is the UNRESTRICTED depth-4 (and depth-5)
search. My 8 nodes was the searchmoves-restricted case. So the two figures agree once the command is stated:
they are different searches, both correct, and neither is a contradiction.

The substantive point is unaffected: the base build gives cp 0 / 0 nodes where the PC build gives mate 1, and
the node count only identifies which command produced it.

node-budget search all return the SAME MOVE with node counts of 84, 8 and 1,344 respectively - so a bare node
