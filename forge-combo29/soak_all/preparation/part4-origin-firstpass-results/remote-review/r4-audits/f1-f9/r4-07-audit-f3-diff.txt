+# R4-07 finding 3
+
+Base `e04556ddc3a430b2e751159b0d46111ef56c8b89`. Audit text and proof read only from `audit/lock-source` at `302a08a272fbe8e8c4463731f3b9cd72d72d3f48`, finding 3 and `forge-combo29/tests_audit/proof_go_mate_cap.cpp`.
+
+## Result
+
+Already correct on this base. No engine change. `CMakeLists.txt` was not edited. No new `FORGE_*` switch.
+
+Finding 3 says `go mate N` caps depth at `2N-1` and therefore misses two forced mates, and that it also stops when the side to move is being mated. On this base the audited positions are solved inside that cap, and a negative mate score does not end the search.
+
+`Worker::search` still limits `go mate N` with `mate_moves * 2 - 1` (`src/search.cpp` lines 1653-1654). Late-move reductions are already skipped when `mate_moves_ != 0` (line 1480), as are the other forward-pruning cuts guarded the same way, so a full-width search to `2N-1` plies is enough for these mates. The iteration break (line 1906) is `score >= mate_in(mate_moves * 2 - 1)`, which is a positive mate in at most N moves. A negative mate score does not satisfy it.
+
+The lock-source proof printed `h2b8` cp `907` and `f6b6` cp `-81`. Reproduced here, the same calls print the mating moves:
+
+```text
+mate-in-2 go mate 2 depth=3 best=a1a6 score=31997 mate=2
+mate-in-2 go depth 6 depth=6 best=a1a6 score=31997
+mate-in-3 go mate 3 depth=5 best=f8c5 score=31995 mate=3
+mate-in-3 go depth 6 depth=6 best=f8c5 score=31995
+being-mated go mate 6 depth=11 score=-31998 best=a2a1 continued=1
+own-mate go mate 6 depth=3 cap=11 score=31997 mate=2 best=b1c2
+pins bench11 312866 bench13 862329 perft5 4865609
+depth10 searches 200 legal 200
+PASS r4_07 go mate
+```
+
+`being-mated` is `8/8/8/8/8/2R5/k7/2K5 b - - 0 1` with `go mate 6`. Depth 2 already reports `score mate -1`. The search continues through depth 11. `own-mate` is mate in 2 with `go mate 6`; that search stops at depth 3 because the mate is ours.
+
+Pins `312866`, `862329`, and `4865609` match. Two hundred depth-10 searches returned a legal move every time.

+[[nodiscard]] int positive_mate_moves(int score) {
+    if (score <= 0 || !forge::is_mate_score(score)) return 0;
+    const int plies = forge::MateValue - score;
+    return (plies + 1) / 2;
+}

+[[nodiscard]] bool move_is_legal(const forge::Board& board, forge::Move move) {
+    if (move.is_none() || !board.is_legal(move)) return false;
+    for (const forge::Move legal : board.legal_moves()) {
+        if (legal == move) return true;
+    }
+    return false;
+}

+Run search_of(forge::Searcher& searcher, const forge::Board& board, const forge::SearchLimits& limits, bool emit) {
+    searcher.clear();

+    std::cout.rdbuf(previous);
+    run.output = captured.str();
+    return run;
+}

+[[nodiscard]] int info_depth(std::string_view line) {
+    constexpr std::string_view key = "info depth ";
+    const auto pos = line.find(key);
+    if (pos == std::string_view::npos) return -1;
+    const char* begin = line.data() + pos + key.size();
+    const char* end = line.data() + line.size();
+    int depth = 0;
+    const auto parsed = std::from_chars(begin, end, depth);
+    if (parsed.ec != std::errc{}) return -1;
+    return depth;
+}

+void expect_no_early_stop_when_mated(forge::Searcher& searcher) {
+    constexpr std::string_view fen = "8/8/8/8/8/2R5/k7/2K5 b - - 0 1";
+    forge::Board board;
+    if (!load_fen(board, fen, "being mated")) return;
+    forge::SearchLimits limits;
+    limits.mate_moves = 6;
+    const Run run = search_of(searcher, board, limits, true);
+
+    bool saw_mate_against = false;
+    bool continued_after = false;
+    std::istringstream lines(run.output);
+    std::string line;
+    while (std::getline(lines, line)) {
+        const int depth = info_depth(line);
+        if (depth < 0) continue;
+        const bool negative_mate = line.find("score mate -") != std::string::npos;
+        if (depth == 2 && negative_mate) saw_mate_against = true;
+        if (saw_mate_against && depth > 2) continued_after = true;
+    }
+
+    const bool still_mated = run.info.score < 0 && forge::is_mate_score(run.info.score);
+    std::cout << "being-mated go mate 6 depth=" << run.info.depth << " score=" << run.info.score
+              << " best=" << forge::Board::move_to_uci(run.info.best_move)
+              << " continued=" << (continued_after ? 1 : 0) << "\n";
+
+    if (!saw_mate_against || !continued_after || run.info.depth <= 2 || !still_mated ||
+        !move_is_legal(board, run.info.best_move)) {
+        fail("go mate stopped early while being mated");
+        std::cerr << run.output;
+    }
+}

+std::vector<forge::Board> build_200_positions() {
+    std::vector<forge::Board> positions;
+    positions.reserve(200);
+    std::uint64_t rng = 0x9E3779B97F4A7C15ULL;
+    auto next_u64 = [&]() {
+        rng ^= rng >> 12U;
+        rng ^= rng << 25U;
+        rng ^= rng >> 27U;
+        return rng * 0x2545F4914F6CDD1DULL;
+    };
+    for (std::size_t seed = 0; seed < SeedFens.size() && positions.size() < 200; ++seed) {
+        forge::Board board;
+        if (!board.set_fen(SeedFens[seed])) continue;
+        for (int step = 0; step < 8 && positions.size() < 200; ++step) {
+            if (board.legal_moves().empty()) {
+                (void)board.set_fen(SeedFens[(seed + 1) % SeedFens.size()]);
+            }
+            if (!board.legal_moves().empty()) positions.push_back(board);
+            const forge::MoveList step_moves = board.legal_moves();
+            if (step_moves.empty()) break;
+            const forge::Move chosen = step_moves[static_cast<std::size_t>(next_u64() % step_moves.size())];
+            forge::Undo undo;
+            (void)board.make_move(chosen, undo);
+        }
+    }
+    return positions;
+}
