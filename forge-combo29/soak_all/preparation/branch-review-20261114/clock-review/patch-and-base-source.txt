+# Report r3-24: hash-table duplicate shadow
+
+- Repository: `github.com/couns0538-sketch/dwqww`
+- Base: `origin/integrate/combo29-all` at `e04556ddc3a430b2e751159b0d46111ef56c8b89`
+- Branch: `grok47/r3-24-tt-duplicate-shadow`
+- Engine: `forge-combo29`
+
+## Where the idea comes from
+
+Audit finding 8 on read-only branch `audit/lock-source` at commit `302a08a272fbe8e8c4463731f3b9cd72d72d3f48`, in `forge-combo29/AUDIT_lock_source.md`. The failing sequence is the proof `forge-combo29/tests_audit/proof_tt_duplicate_shadow.cpp` on that commit. This branch does not modify `audit/lock-source`. The proof is kept, with a pass/fail check, at `forge-combo29/tests_r3_24/proof_tt_duplicate_shadow.cpp`.
+
+## What was wrong
+
+`TranspositionTable::probe` remembers a slot, then search continues, then `store` writes only that slot. The slot can be stale:
+
+1. A miss on `key_a` selects an empty slot.
+2. A different key in the same 4-entry cluster is stored into that slot.
+3. A later probe of `key_a` selects another slot and stores a deep entry.
+4. The first search stores a shallow result through the original probe. `same_position` is false, so the depth guard does not apply, and a second copy of `key_a` is written.
+5. The next probe walks the cluster from the front and returns the shallow copy. The deeper entry stays in the table and is never seen.
+
+That happens when a helper thread, or a nested search of the same position, stores `key_a` before the outer store. The proof builds that slot sequence on one thread.
+
+## Change
+
+In both store implementations (`store_body`, used when `FORGE_SPD_TT_NOTLS` is 1, and `store` in the other build), after the stripe lock is taken, the cluster is scanned for an occupied entry with this verification key. If one exists, that entry is updated. Otherwise the probe-time slot is used, as before.
+
+The existing replacement rule is unchanged: an exact bound, a different position, `depth + 4` above the stored depth, or a generation change still replaces the payload. A shallow non-exact store therefore does not overwrite a deeper score once it is aimed at the real entry. A store that is not admitted still replaces the move on that entry. That was already the same-position rule; it is not a second copy.
+
+No UCI option. The fix is always on. The three default pins did not move, so there was no reason to leave it off.
+
+`CMakeLists.txt` is unchanged. The test is not part of the CMake target.
+
+## Pins
+

+    const forge::TTProbe p_shallow = tt.probe(key_a);

   216	TranspositionTable::ExclusiveLease::ExclusiveLease(TranspositionTable& table)
   217	    : table_(table), previous_(active_lease_), gate_(table.exclusive_gate_, std::defer_lock) {
   218	    if (!table_.has_exclusive_access()) {
   219	        gate_.lock();
   220	        table_.exclusive_requested_.store(true, std::memory_order_release);
   221	        try {
   222	            // A foreign accessor either completes before its stripe drains,
   223	            // or observes the request after acquiring that drained stripe.
   224	            for (std::size_t i = 0; i < StripeCount; ++i) {
   225	                const std::lock_guard<std::mutex> drain(table_.stripes_[i].mutex);
   226	            }
   227	        } catch (...) {
   228	            table_.exclusive_requested_.store(false, std::memory_order_release);
   229	            throw;
   230	        }
   231	    }
   232	    active_lease_ = this;
   233	}

   248	std::unique_lock<std::mutex> TranspositionTable::lock_stripe(std::size_t index) const {
   249	    std::mutex& stripe = stripes_[index % StripeCount].mutex;
   250	    if (has_exclusive_access()) return std::unique_lock<std::mutex>(stripe, std::defer_lock);
   251	    for (;;) {
   252	        std::unique_lock<std::mutex> lock(stripe);
   253	        if (!exclusive_requested_.load(std::memory_order_acquire)) return lock;
   254	        // Never wait for the gate while holding a stripe: the owner drains it.
   255	        lock.unlock();
   256	        const std::lock_guard<std::mutex> wait(exclusive_gate_);
   257	    }

   357	TTProbe TranspositionTable::probe(std::uint64_t key) const {
   358	    TTCluster& cluster = cluster_for(key);
   359	    const std::size_t index = static_cast<std::size_t>(&cluster - clusters_.get());
   360	    const auto lock = lock_stripe(index);
   361	    auto snapshot = [&](const TTEntry& entry, bool hit) {
   362	        TTProbe result;
   363	        result.entry = entry;
   364	        result.hit = hit;
   365	        result.owner_ = this;
   366	        result.cluster_ = index;
   367	        result.slot_ = static_cast<std::uint8_t>(&entry - cluster.entries.data());
   368	        result.epoch_ = epoch_;
   369	        result.key_ = key;
   370	        return result;
   371	    };
   372	    const std::uint32_t key32 = verification_key(key);
   373	    for (TTEntry& entry : cluster.entries) {
   374	        if (entry.key32 == key32 && entry.occupied()) {
   375	            // Reused entries remain recent even when search returns a TT cutoff.
   376	            if (entry.generation() != generation_) {
   377	                entry.gen_bound = static_cast<std::uint8_t>(
   378	                    (static_cast<unsigned>(generation_) << 3U) | (entry.gen_bound & 7U));
   379	            }
   380	            return snapshot(entry, true);
   381	        }
   382	    }
   383	    const TTEntry* replace = &cluster.entries[0];
   384	    auto relative_age = [this](const TTEntry& entry) {
   385	        return static_cast<int>((32 + generation_ - entry.generation()) & 31U);
   386	    };
   387	    for (const TTEntry& entry : cluster.entries) {
   388	        if (!entry.occupied()) return snapshot(entry, false);
   389	        if (entry.depth - 4 * relative_age(entry) < replace->depth - 4 * relative_age(*replace)) replace = &entry;
   390	    }
   391	    return snapshot(*replace, false);
   392	}

   394	void TranspositionTable::store(const TTProbe& probe, std::uint64_t key, int score, int eval, Move move, int depth,
   395	                               Bound bound, bool pv, std::uint16_t halfmove_clock) {
   396	    // Reject default, foreign or lifecycle-stale handles without touching storage.
   397	    // Lifecycle operations themselves must not run concurrently with search.
   398	    if (probe.owner_ != this || probe.epoch_ != epoch_ || probe.key_ != key ||
   399	        probe.cluster_ >= cluster_count_ || probe.slot_ >= 4) return;
   400	    const auto lock = lock_stripe(probe.cluster_);
   401	    TTEntry* entry = &clusters_[probe.cluster_].entries[probe.slot_];
   402	    const std::uint32_t key32 = verification_key(key);
   403	    const bool same_position = entry->key32 == key32 && entry->occupied();
   404	    if (!move.is_none() || !same_position) entry->move = move;
   405	    if (bound == BoundExact || !same_position || depth + 4 > entry->depth || entry->generation() != generation_) {
