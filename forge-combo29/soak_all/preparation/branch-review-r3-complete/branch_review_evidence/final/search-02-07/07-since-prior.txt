+# NullSeeVeto
+
+`NullSeeVeto` is one UCI check option. It defaults to false. With it left off, null-move pruning is the same search as before.
+
+The rule comes from this task, not from another engine. Null-move pruning cuts a node off when the side to move can pass and the position still fails high. That cutoff is refused when the opponent already has a legal capture of a dearer piece by a cheaper one, and this engine's static exchange evaluation does not call that capture a material loss (`see_ge` at threshold 0). A piece can be attacked by a cheaper piece and still be safe: if the exchange loses material for the capturer, the cutoff stays allowed. The prices are this engine's `SeePieceValue`. Knights and bishops share that price, so one taking the other is not a cheaper-for-dearer capture. The king is ranked above the queen because `SeePieceValue` stores 0 for the king as a sentinel inside the exchange walk, not as a material price. No table, constant, or routine was copied from another engine.
+
+The check runs only when a null-move cutoff would otherwise be attempted, and only when the option is on. The board is restored before search continues. Turning the option off does not call the check.
+

+
+Threads 1, Hash 16, OwnBook false, every other option at its default. Measured on the release build (`cmake -S forge-combo29 -B build -DCMAKE_BUILD_TYPE=Release -DFORGE_PORTABLE=ON -DFORGE_MARCH=x86-64-v3`) before the source change, and again after it.

+

+## Option on
+
+`setoption name NullSeeVeto value true`, then bench 13: 929140 nodes. Same count on the Clang sanitizer binary. That is a different tree from 862329, so the option is live. This is not a strength result.
+
+## Tests
+
+`forge-combo29/tests_r3_07/null_see_veto_test.cpp` checks the predicate on constructed positions, including a loose queen taken by a knight, a rook defended by a pawn whose exchange still wins for the knight, and a rook on the promotion rank whose recapturing pawn promotes and whose exchange loses. The last of those must not veto. Equal captures, a bishop taking a pawn, a pinned capture, and an en-passant position must not veto either. Each of 200 searches to depth 10, with the option on, Hash 16, and one thread, returned a best move that was in the legal list. Every move of the returned principal variation was legal in sequence. The positions are a deterministic walk from the start position.
+
+The same test was built with Clang 18.1.3 `-fsanitize=address,undefined -fno-omit-frame-pointer` against objects built the same way, and run with halt-on-error for both sanitizers and leak detection on. It printed `positions ok`, `searches 200 legal`, and `NullSeeVeto tests passed`, and exited 0 with no sanitizer diagnostic. An earlier g++ 13.3.0 build with the same sanitizers also exited 0 on 200 depth-10 searches of this search code.

+bool null_see_veto_threat(Board& board) {
+    // Same prices as SEE, except the king. SeePieceValue prices a king at 0
+    // because the exchange walk treats it as a sentinel, not as the cheapest piece.
+    constexpr int KingWorth = 100000;
+    auto worth = [](int type) {
+        return type == King ? KingWorth : SeePieceValue[static_cast<std::size_t>(type)];
+    };
+    NullUndo undo;
+    board.make_null_move(undo);
+    bool threat = false;
+    const MoveList moves = board.pseudo_legal_moves(true);
+    for (const Move& move : moves) {
+        if (!move.is_capture()) continue;
+        const int attacker = worth(piece_type(board.moved_piece(move)));
+        const int victim = worth(piece_type(board.captured_piece(move)));
+        if (attacker >= victim) continue;
+        if (!board.is_legal(move) || !board.see_ge(move, 0)) continue;
+        threat = true;
+        break;
+    }
+    board.unmake_null_move(undo);
+    return threat;
+}

+#include "forge/search.hpp"

+int failures = 0;

+void expect(bool condition, std::string_view message) {
+    if (condition) return;
+    std::cerr << "fail: " << message << '\n';
+    ++failures;
+}

+struct Rng {
+    std::uint64_t state;
+    std::uint64_t next() {
+        std::uint64_t x = state;
+        x ^= x << 7;
+        x ^= x >> 9;
+        x ^= x << 8;
+        state = x;
+        return x;
+    }
+};
+
+int enemy_exchange(forge::Board& board, std::string_view uci) {
+    forge::NullUndo undo;
+    board.make_null_move(undo);
+    int score = 999999;
+    bool found = false;
+    const forge::MoveList moves = board.pseudo_legal_moves(true);
+    for (const forge::Move& move : moves) {
+        if (forge::Board::move_to_uci(move) != uci) continue;
+        found = board.is_legal(move);
+        score = board.static_exchange(move);
+        break;
+    }
+    board.unmake_null_move(undo);
+    if (!found) return 999999;
+    return score;
+}
+
+void expect_threat(const char* fen, bool threat, const char* label) {
+    forge::Board board;
+    std::string error;
+    expect(board.set_fen(fen, &error), label);
+    expect(!board.in_check(forge::White) && !board.in_check(forge::Black), label);
+    const std::string before = board.fen();
+    const bool got = forge::null_see_veto_threat(board);
+    expect(board.fen() == before, label);
+    expect(got == threat, label);
+    if (got != threat) std::cerr << "  fen " << fen << " threat " << got << '\n';
+}
+
+void expect_exchange(const char* fen, const char* uci, bool loses, const char* label) {
+    forge::Board board;
+    expect(board.set_fen(fen), label);
+    const int score = enemy_exchange(board, uci);
+    expect(score != 999999, label);
+    expect(loses ? score < 0 : score >= 0, label);
+    if ((loses && score >= 0) || (!loses && score < 0) || score == 999999) {
+        std::cerr << "  " << label << " see " << score << " move " << uci << '\n';
+    }
+}

+void check_searches() {
+    forge::tune::NullSeeVeto = true;
+    forge::Searcher searcher(16, 1);
+    Rng rng{0x5ee0d011ULL};
+    int done = 0;
+    while (done < 200) {
+        forge::Board board;
+        expect(board.set_fen(forge::Board::StandardStartFen), "start fen");
+        searcher.clear();
+        for (int ply = 0; ply < 24 && done < 200; ++ply) {
+            const forge::MoveList legal = board.legal_moves();
+            if (legal.empty()) break;
+            forge::SearchLimits limits;
+            limits.depth = 10;
+            const forge::SearchInfo info = searcher.search(
+                board, limits, false, forge::Searcher::TTAccess::Exclusive);
+            bool listed = false;
+            for (const forge::Move& move : legal) {
+                if (move == info.best_move) listed = true;
+            }
+            if (!listed || info.best_move.is_none() || !board.is_legal(info.best_move)) {
+                std::cerr << "fail: illegal move " << forge::Board::move_to_uci(info.best_move)
+                          << " fen " << board.fen() << " search " << done << '\n';
+                ++failures;
+                return;
+            }
+            forge::Board line = board;
+            for (const forge::Move& pv_move : info.pv) {
+                bool pv_listed = false;
+                const forge::MoveList pv_legal = line.legal_moves();
+                for (const forge::Move& candidate : pv_legal) {
+                    if (candidate == pv_move) pv_listed = true;
+                }
+                if (!pv_listed || !line.is_legal(pv_move)) {
+                    std::cerr << "fail: illegal pv move " << forge::Board::move_to_uci(pv_move)
+                              << " fen " << line.fen() << " search " << done << '\n';
+                    ++failures;
+                    return;
+                }
+                forge::Undo pv_undo;
+                if (!line.make_move(pv_move, pv_undo)) {
+                    std::cerr << "fail: pv move rejected " << forge::Board::move_to_uci(pv_move)
+                              << " search " << done << '\n';
+                    ++failures;
+                    return;
+                }
+            }
+            ++done;
+            if (done % 40 == 0) std::cout << "searches " << done << '\n';
+            const forge::Move played = legal[static_cast<std::size_t>(rng.next() % legal.size())];
+            forge::Undo undo;
+            if (!board.make_move(played, undo)) {
+                std::cerr << "fail: could not play " << forge::Board::move_to_uci(played) << '\n';
+                ++failures;
+                return;
+            }
+        }
+    }
+    std::cout << "searches " << done << " legal\n";
+}
