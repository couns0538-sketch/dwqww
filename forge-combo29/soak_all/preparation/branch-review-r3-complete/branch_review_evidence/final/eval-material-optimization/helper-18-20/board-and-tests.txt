# Lazy network accumulator

Branch `grok47/r3-18-lazy-net-accumulator`, built from `e04556dd`. No new UCI option. Search options used for every check below: Threads 1, Hash 16, OwnBook false, every other option left at its default. Build:

```
cmake -S forge-combo29 -B build -DCMAKE_BUILD_TYPE=Release -DFORGE_PORTABLE=ON -DFORGE_MARCH=x86-64-v3
cmake --build build -j
```

This machine is a 4-core Intel Xeon VM, g++ 13.3, `-march=x86-64-v3` with the portable switches (no PEXT, no AVX-512). The numbers are measurements on that machine. They are not a strength result.

## Where the idea comes from

The network state is one vector per colour, each a sum of piece-square columns. A move changes only a few of those columns. This search already applied those columns inside static evaluation rather than inside `make_move`: `record_move` stored a change list, and `static_evaluate` walked back to the last finished vector and called `nnue::update`.

On an instrumented bench 13 (862329 nodes) that list was built 826208 times and the columns were added 655136 times. The gap is moves that never reach an evaluation: transposition cutoffs, positions in check, and stand-pat cutoffs. A null move was 41488 of the updates, and a null move does not change the piece set, so the copy is the same bits as the parent vector.

This change keeps that rule and tightens it. Making a move stores the mover, the captured piece, and the side, and builds the change list then, before the move is played. The feature columns are still added only when an evaluation reads that ply. A null move does not copy the vector; evaluation reads the parent. A quiet move or a capture writes each new hidden unit with the same sum as `nnue::update`, and the output layer consumes that unit from the register that was just stored, in the same lane order as `nnue::evaluate`. Castling and every other shape still call `update` and then `evaluate`. Nothing here is taken from another engine's source.

#include "forge/board.hpp"
#include "forge/eval.hpp"
#include "forge/search.hpp"

#include <cstdint>
#include <cstdio>
#include <cstdlib>
#include <string>
#include <vector>

namespace {

std::uint64_t rng_state = 0xC0FFEE1234ULL;

std::uint64_t next_rng() {
    rng_state ^= rng_state >> 12;
    rng_state ^= rng_state << 25;
    rng_state ^= rng_state >> 27;
    return rng_state * 2685821657736338717ULL;
}

void write_pod(const void* data, std::size_t size) {
    if (std::fwrite(data, size, 1, stdout) != 1) std::exit(2);
}

struct EvalRecord {
    std::int32_t uncached = 0;
    std::int32_t cached = 0;
    std::int32_t hce = 0;
    std::int32_t nnue = 0;
    std::int32_t total = 0;
    std::int32_t in_check = 0;
};

struct SearchRecord {
    char move[8]{};
    std::int32_t score = 0;
    std::uint64_t nodes = 0;
};

void emit_eval(forge::Board& board, forge::Evaluator& evaluator) {
    EvalRecord record;
    record.uncached = forge::Evaluator::evaluate_uncached(board);
    record.cached = evaluator.evaluate(board);
    const forge::EvalComponents parts = forge::Evaluator::static_eval_components(board);
    record.hce = parts.hce;
    record.nnue = parts.nnue;
    record.total = parts.total;
    record.in_check = parts.in_check ? 1 : 0;
    write_pod(&record, sizeof record);
}

void play_random(forge::Board& board, int& ply) {
    const forge::MoveList legal = board.legal_moves();
    if (legal.empty() || ply >= 80 || (next_rng() % 64ULL) == 0ULL) {
        if (!board.set_fen(forge::Board::StandardStartFen)) std::exit(3);
        ply = 0;
        return;
    }
    const forge::Move move = legal[static_cast<std::size_t>(next_rng() % legal.size())];
    forge::Undo undo;
    (void)board.make_move(move, undo);
    ++ply;
}

void walk_hce(int count) {
    forge::Board board;
    int ply = 0;
    std::int64_t sum = 0;
    for (int i = 0; i < count; ++i) {
        sum += forge::Evaluator::evaluate_uncached(board);
        play_random(board, ply);
    }
    std::fprintf(stderr, "hce_sum %lld\n", static_cast<long long>(sum));
}

void walk_hot(int count) {
    std::vector<forge::Board> boards;
    boards.reserve(static_cast<std::size_t>(count));
    forge::Board cursor;
    int ply = 0;
    for (int i = 0; i < count; ++i) {
        boards.push_back(cursor);
        play_random(cursor, ply);
    }
    forge::Evaluator evaluator;
    std::int64_t sum = 0;
    for (const forge::Board& board : boards) sum += evaluator.evaluate(board);
    evaluator.clear();
    for (int repeat = 0; repeat < 20; ++repeat) {
        for (const forge::Board& board : boards) sum += evaluator.evaluate(board);
    }
    std::fprintf(stderr, "hot_sum %lld\n", static_cast<long long>(sum));
}

void walk_eval(int count) {
    forge::Board board;
    forge::Evaluator evaluator;
    int ply = 0;
    for (int i = 0; i < count; ++i) {
        emit_eval(board, evaluator);
        play_random(board, ply);
    }
}

void walk_search(int count) {
    forge::Searcher searcher(16, 1);
    forge::Board board;
    int ply = 0;
    forge::SearchLimits limits;
    limits.depth = 8;
    for (int i = 0; i < count; ++i) {
        const forge::SearchInfo info = searcher.search(board, limits, false, forge::Searcher::TTAccess::Exclusive);
        SearchRecord record;
        const std::string text = forge::Board::move_to_uci(info.best_move);
        for (std::size_t c = 0; c < text.size() && c < sizeof record.move; ++c) record.move[c] = text[c];
        record.score = info.score;
        record.nodes = info.nodes;
        write_pod(&record, sizeof record);
        play_random(board, ply);
    }
}

} // namespace

int main(int argc, char** argv) {
    const std::string mode = argc > 1 ? argv[1] : "eval";
    const int count = argc > 2 ? std::atoi(argv[2]) : 1000000;
    if (mode == "search") walk_search(count);
    else if (mode == "hce") walk_hce(count);
    else if (mode == "hot") walk_hot(count);
    else walk_eval(count);
    return 0;
}
