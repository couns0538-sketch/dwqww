# T04 pre-gate bug checklist - Elo-losing search / movegen bug patterns

Use before a search candidate goes to the crew gate. Each row: the pattern, a real fix commit or PR that shows it
(MIT engines: diff read; Stockfish: GPL, commit message only), the symptom, and a cheap box test (most reuse checks
Forge already has: bench / perft pins, OFF = lock pins, ON live, mate probe, mutant check (skill forge-engine-verify),
warm-TT harness (forge-search-bug-hunt), ASan + UBSan self-play (forge-candidate-checks)). "Lock" = FD3A5190 source.
