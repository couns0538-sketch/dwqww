# IDEA_SOURCE (R9, SPSA search-parameter tuning)

Ideas only: no code from any of these projects is in this branch. The tuner (`opus_r9/tuner/`), the R9Tune engine
layer and every tool here are new code. Sources were read on 2026-10-29 (pages linked below).

| source (licence) | what it describes | idea taken | where in R9 |
|---|---|---|---|
| Fishtest wiki "Creating my first test", SPSA section ([page](https://github.com/official-stockfish/fishtest/wiki/Creating-my-first-test)); fishtest issue #535 ([issue](https://github.com/official-stockfish/fishtest/issues/535)) (repository licence not shown by the GitHub API; ideas only) | parameter line `name, value, min, max, c_end, r_end`; schedule `ck = c0 / (1 + k)^gamma`, `ak = a0 / (A + 1 + k)^alpha`, `rk = ak / ck^2`; one iteration = 2 games played with `value + ck` and `value - ck`; update `value += ck * rk * (wins - losses)`; c_end / r_end are the values at the end of the run; clipping to min/max | the schedule and the update rule, counted in game pairs; the per-parameter c_end / r_end inputs; deriving c0, a0 from the end values and the planned length | `r9_spsa.py` (`Run.c0`, `Run.a0`, `ck`, `ak`, update `theta += a_k/c_k * R * delta`), the config's `params[].c_end/r_end` |
