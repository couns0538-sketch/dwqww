**Reviewer:** one subagent on another model (Opus), Read / Grep / Glob only, no shell (a subagent's shell is not pinned to cores 3-6).

**Asked:** ways the harness could report "no difference" wrongly, or a false difference.
**Dispatched 19:16, returned 19:41.** By then harness 1 had already run 13 million auxiliary comparisons and 1.3 million release-exe comparisons per candidate, all equal. Those runs are kept under `out\job3\runs\h1\` as an earlier run of the same corpus. They are not added to the counts: every counted result was produced again with harness 2.
