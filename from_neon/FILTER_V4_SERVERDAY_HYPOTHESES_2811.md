### Rank 1 — **HYPOTHESIS H1 (Within-Game Decorrelation + Cross-Round Dedup, `D-01`)**
- **Statement:** Subsampling correlated within-game positions (`101.32` quiet rows/game, `corr = 0.99697`, `3.145%` cross-round exact duplicates mostly at `ply >= 81`) while keeping `100%` of `pieces <= 5` endgame positions will reduce gradient redundancy and late-game overfitting without harming `OB0` capacity.
- **Concrete test (`F_FIX_25R_v3`):** Run `run_f_fix_v3_prod_p2.py` (`--late-keep-num 1 --late-keep-den 2 --dedup-cross-round`) on `r0178..r0202` against `OPUS_R1_live768_skipnoisy` (and against `F_FIX_25R_v2` if `v2` wins H1) at declared 250k SPRT `[0,10]` + `2,000g @ 6+0.06` clock confirmation.
- **Server Day `2.0B` scaling:** If `2.0B` positions are generated on Server Day (`G:\nnuelab4`), **HYPOTHESIS**: `random_fen_skipping` (e.g., keeping `1/4` to `1/8` of `pieces >= 6` rows per game at datagen/pack time rather than storing 101 correlated rows/game) cuts disk I/O and increases unique-position diversity per GPU epoch by `4x–8x` at fixed VRAM.

### Rank 2 — **HYPOTHESIS H2 (Score-Quality Predicates `F-03`, `F-03b` vs WDL-Probabilistic Filtering)**
- **Statement:** Removing `res == 0 & |score| >= 400` (`64,679`/round) and `res != 0 & score*res <= -300` (`6,319`/round) eliminates high-magnitude contradictory targets (~`0.58%` of quiet rows) that pull midgame/endgame weights against game reality. - **Concrete test:** Already bundled in `F_FIX_25R_v3` (`F-03=400`, `F-03b=300`); for `v4` / Server Day, compare `wld_filtered` (calibrated to Forge's `eval_scale=400`) vs fixed `F-03/F-03b` thresholds on identical `25R` or `2.0B` data.

- **Statement:** Forge keeps `100%` of plies `8..19` (`9.47%` of quiet rows, immediately following 8 random moves) and `100%` of `232,370` adjacent `0 -> 0` repetition pairs/round, while retaining `32`-piece positions at `1.0x` vs `nnue-pytorch`'s `0.75x`. **HYPOTHESIS**: applying `nnue-pytorch`-style soft early-ply attenuation (`ply 8..19`), thinning consecutive `score == 0, res == 0` runs (`>2` consecutive zeros in a game), and adopting a piece-count target spline (`pc=2..5` preserved, `pc=32` downweighted to `0.75x`) improves effective training diversity per epoch at `2.0B` scale.
