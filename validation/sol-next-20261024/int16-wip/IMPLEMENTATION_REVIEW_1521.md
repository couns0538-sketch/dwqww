# Read-only review of H256 runtime int16 scratch

Reviewed the scratch `src/nnue_int16.inc`, dispatch changes in `src/nnue.cpp`, `src/uci.cpp`, and `include/forge/nnue.hpp`. No builds, engine executions, tests, timing, Git operations, or implementation edits by this reviewer.

No blocking correctness issue found in the inspected path. This is source review, not validation acceptance.

- **Overflow and packing:** activation is bounded to [0,4096], then shifted to [0,16384], and mulhrs yields [0,8192]. Each signed madd has two products, at most 536,870,912 in magnitude even for -32768 output weights. Adding ours and theirs is at most 1,073,741,824, so signed32 is safe. The implementation widens to signed64 before cross-group accumulation and performs the final reduction in signed64. AVX2 packed weight order matches the lane interleave. The scalar square formula `(a*a+1024)/2048` matches this SIMD rounding.
- **Representability/fallback:** constructor checks both scales, the 16-lane group requirement, and the exact-float-grid accumulator/intermediate bound. The locked net's all-feature bound 1,635,680 plus four maximum columns 41,292 gives 1,676,972, safely below 2^24 and int32. The all-int16 output bound is below 2^53. Rejection returns with `representable=false`; no abort is present. `set_int16(true)` selects only representable weights. UCI prints an info string and retains float when unavailable.
- **Runtime tags/lifecycle:** refresh selects the representation; update and evaluate follow the parent/accumulator tag. This intentionally lets an existing tree remain internally consistent. For the UCI path, every setoption first stops and joins search workers. Every new Worker search invalidates all accumulators and refreshes the root. Consequently ON->OFF and OFF->ON search transitions receive new roots; the global non-atomic selector has no identified concurrent UCI writer. TT is cleared on a successful parsed option change. Zero-dirty and in-place updates preserve the tag correctly.
- **OFF identity:** the existing float calculations and AVX-512/alignment code are textually unchanged, apart from representation dispatch and clearing the float tag. The new fields do enlarge `Accumulator` by approximately 2048 bytes at H256, costing about 272 KiB per worker over 136 search stack entries even with the option OFF. OFF arithmetic identity therefore still needs all five required bench checks; OFF timing should not be assumed identical.
- **Network identity:** both scratch and checkout `nnue_weights.inc` SHA-256 are `74c4009d86b7d3a5ae9e6119d0890e5b923508f4063161bb4bc1539aab275b1b`. No network or trainer change was found.
