## Proof lifetime and purity

Only a successful Main/GoodCaptures `see_ge(move,0)` atsearch360 produces the proof. The TT move is explicitly skipped there (359); thus a proven returned move cannot trigger same-move TT singular verification before its extension consumer. Producer/consumers operate on the same Board and complete Move, including flags/promotion. `is_legal` atboard577–598 and `gives_check` at671–700 compute local occupancy/masks and do not mutate the Board. History lookups read tables. Actual `see_ge` at932–1022 uses local values/occupancy and const Board reads; its promotion helper21–115 uses a local gain stack and constexpr SeeValue, with no history, clock or RNG writes. Const qualification alone is not the purity argument.

A future result carrier must reset to **no proof at the start of every next() call**, including calls that return none. It is set only on that successful GoodCaptures return and consumed immediately alongside the exact returned Move. It must stay false for MainTT/QsTT/EvasionTT, killers/counter/quiet moves, evasions, QsCaptures and BadCaptures. Give every newly constructed picker an empty proof. Do not infer proof from a move being a capture, a stored stage after returning, an old Boolean, a positive ordering score or another picker. A Board key is useful diagnostic evidence but is not alone a proof against hash collision or a replacement for tracing the unchanged Board scope.

Normal sibling make/unmake occurs after these consumers; a future optimization must never carry this proof across make/null/unmake, another next(), another frame or another picker. Full Move equality and a fresh picker-event identity belong in diagnostic joins; don't key it by from/to alone. No shared/global SEE cache is needed.

## Two separate reuse levels

1. **Exact query:** a true result at0 answers the same `see_ge(move,0)` extension question at1106, because the inputs and function are unchanged. Preserve all other extension predicates and short-circuit order. No inference about negative thresholds is needed.
2. **Weaker query:** consume `see_ge(move,0)==true` for main1077 only with an explicit actual consumer threshold<=0 and a justified actual-function monotonicity argument. Castling and the promotion helper compare a threshold-independent value directly. The ordinary shortcut implementation alternates threshold arithmetic along an attacker sequence whose geometry/LVA selection is threshold-independent until an early exit; that motivates, but is not itself a complete proof of, its minimax threshold predicate. Review each early return/king branch and verify legal API controls. Any counterexample blocks this level; do not change SEE semantics to make reuse pass. If the proof remains incomplete, limit a candidate to exact-zero reuse.

Add worker-local counters at GoodCaptures, main noisy pruning and check extension; separate qsearch/evasion/TT/quiet/bad stages as controls. For each eligible pair, retain picker-event ID, full Move, Board identity and bounded legal FEN witness, depth, actual threshold, original answer and producer answer. Reset lineage must be observable, including consecutive next() calls and returns of none.

Count actual work categories: initial fast returns955/957, promotion-helper entries and gain iterations, ordinary exchange iterations and pinner scans. Report saved-call opportunity separately from saved expensive work. Per-call timer instrumentation would perturb the small operations; do not treat instrumented elapsed/NPS as a performance result. Source duplication may produce little useful cost, and proof bookkeeping can cost more than the removed calls.

Require unchanged complete canonical engine outputs for the observation-only export before trusting counts. Start with cheap existing default fixed-work workloads under explicit bounded nodes/depth and closed owned-process cleanup; any extended workload needs a separate justified bound, not an endless search for a witness. Preserve original commands, source/compiler/network/binary hashes, streams and unknown exit facts. A count of zero or negligible expensive work is a legitimate negative screen.
