## Why this is an independent experiment

In frozen47f source, `src/search.cpp:913` sets `ss->static_eval` from the already-corrected evaluation. A TT score may subsequently replace local `eval` at915–917, but does not replace `ss->static_eval`. The only update call at1194 passes the corrected stack value. Guards1190–1193 admit noncheck, nonexcluded, nonmate results with no capturing best move when a bound is usable in the residual's direction. The patch changes none of those guards. The same residual is formed once and supplied to both table entries at630–631.

`CorrectionGrain=256`, `CorrectionLimit=8192`, and the target clip is2048. Thus diff is always an integer multiple of256 for valid integer search scores, including clipped endpoints. Incremental `diff*weight/256` has no fractional remainder. Current EMA division, material scaling and final correction division still use C++ truncation toward zero. Rows are selected by side to move; there is no extra sign inversion in these methods.

## Expected full-search consequences

Correction reads affect qsearch stand pat and futility at785–797, main-search improving at923–925, razoring at930, reverse futility at936, null-move eligibility/reduction at941–947, ProbCut SEE threshold at985, and quiet/capture futility at1043/1054. The residual-direction guards1192–1193 also observe the changed static evaluation. Search nodes, scores, PV and pruning decisions may change; exact search parity is not an acceptance criterion for this algorithmic ablation. Raw TT evaluation storage, the network and correction-table ownership do not change.

The existing EMA learns toward a residual that already includes current correction. Removing decay makes fixed-target learning closer to that target but removes regularization. It also changes effective reachable range: starting from zero the EMA is confined to the ±2048 target envelope; at depth15 the saturated integer endpoint is±2033. Incremental updates can reach the unchanged ±8192 entry clamp. Under material100, two equal entries can therefore supply±64cp rather than a saturated±15cp in the direct fixed-residual fixture. Equal residual increments preserve any entry disparity unless clipping intervenes, while EMA contracts it. A shared material index can transfer an update between genuinely different pawn structures without any accidental hash collision. These are substantive parts of this single ablation, not reasons to retune another constant simultaneously.

## Permanent actual-method regression design

Add a small core-linked test using the existing `forge::SearcherTestProbe` friendship, as demonstrated by `probe.cpp`; do not create an alternate correction implementation. The meaningful behavior contract is: feed the real corrected result back into the real update repeatedly for a fixed raw evaluation and target, then assert the observed correction and table states. Keep both signs, material0 as a one-table control and material100 as the production path. The Δ6, depth15,4096-update fixture discriminates current attenuation from the requested incremental behavior without depending on engine move choice, timings or a copied formula. Baseline must fail this new behavior contract; that expected failure demonstrates an algorithmic difference, not an existing chess defect.

Retain focused endpoint/zero-residual, signed rounding, side separation, exact same-material/different-pawn fixtures, and one conflicting update through the second pawn structure. Discover the actual material slot by an isolated method update and inspect its unique modified slot rather than duplicating the private material hash. Preseed unequal pawn/material entries once and verify both consume the same precomputed residual. These checks cover the changed semantics and table coupling rather than asserting syntax.

Before candidate acceptance, the parent task should run the relevant full CTest suite and its sanitizer policy on the integrated source, then freeze any authorized strength comparison separately with OwnBook=false, A/A calibration and the project's fresh equal-clock paired SPRT policy. These arithmetic probes establish neither speed nor playing strength. No engine search or match is run by this package.
