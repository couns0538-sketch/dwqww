# Chess Engine Forge – match records

Plain PGN files of every test and validation match played while developing
Chess Engine Forge from 5.31.0 to 6.3.0 (35 files, 51,752 games), unmodified
fastchess output. `EXPERIMENTS.md` describes each experiment, its result and the
decision taken, and its final section maps every file in `pgns/` to its match.
The engine source and release archives are on the branch
`cursor/engine-strength-overhaul-66cc`.
