## Summary of Coverage (`35` Failure Modes, `NF-01`–`NF-35`)

Each entry specifies: **(1) what can go wrong**, **(2) how it is noticed**, **(3) what the unattended script does**, and **(4) the rehearsal/planted test that proves the guard works**:

- **A. Pre-flight, host substitution & package integrity (`NF-01`–`NF-03`):** Under-provisioned/substituted host (including Linux cgroup `cpu.max` / `cpuset` caps smaller than `nproc`, unmounted NVMe vs small `/`), unapproved/modified/extra/CRLF scripts violating the 3-`YES` ledger, and server-vs-PC clock skew or mid-day NTP jumps (use `CLOCK_MONOTONIC` elapsed anchor for `23:00` deadline).
- **B. Build, ISA, compiler traps & engine identity (`NF-04`–`NF-07`):** Wrong ISA / slow microcoded PEXT, degraded PGO/LTO (`115806Z` GCC PGO-no-LTO `-9.5%`/`-20%` regression + `N16` silent profile drop), silent UCI option failure / wrong option order / silent NNUE fallback (`N15`/`N17`/`W5(b)`), and cross-machine parity / checksum byte-spec mismatch (`W5(i)`/`121010Z`/`121724Z`).
- **C. Pilot, budget & scaling degradation (`NF-08`–`NF-10`):** Counting server-local rows instead of home-verified kept rows (`W5(g)`), pilot below required rate or thermal throttling decay after minutes 5–10 (triggering pre-declared fallback or Hour-1 abort), and optional matches stealing core-hours needed for the 2B self-play target (hourly trailing-rate check preempting matches at chunk boundary).
- **D. Server workers, opening identity & unattended execution (`NF-11`–`NF-16`):** Worker/`forge` crash, `SIGKILL`, OOM kill, hang, or 64 KiB stderr pipe deadlock (clean process-group kill, same logical-slot respawn, crash circuit breaker); omitted `ucinewgame` (`N12`); malformed `position` line or swapped opening-to-result binding (`A23`); allocator crash/outage or colliding wall-clock seeds (`W5(f)`/`F3`/`F4`); terminal/SSH/AI-session drop (`SIGHUP` detachment on Linux & Windows); duplicate supervisor double-start (`flock`/mutex).
- **E. Sealing, packing, transfer & network outages (`NF-17`–`NF-20`):** Torn/half-written piece download (two-phase `*.tmp` + `fsync` + atomic rename with `.seal.json` commit marker published last); network outage or hung half-open SSH (`BatchMode=yes` + `ServerAliveInterval` + outer timeout + server never blocking on network); premature deletion of unconfirmed pieces (default: keep all `~9.2 GB` on server all day); payload corruption with valid transport SHA-256 (`W5(d)`).
- **F. Home PC receiving, A26 ordering, storage floors, rescoring & filtering (`NF-21`–`NF-25`):** Home disk floors (`40/30/30 GiB`) vs `~186 GiB` uncompressed round text (stay packed, unpack one round at a time, filter -> pack -> drop text, check `disk_usage()` before every step); `A26` arrival-order contamination, premature release, post-seal conflict, and conflicting complete records; `A14` post-game TB rescoring disabled/missing/sign-flipped (stop on any single failed probe + 3-orientation fixture + `0/10,000` alert); Windows sleep/Update reboot/Defender `WinError 32` `os.replace` lock; decoupling home fetch+verify (`~130 KB/s`) from slower home rescore+filter so server delivery never stalls.
- **G. Server disk, memory & OS limits (`NF-26`–`NF-27`):** Core-dump/log disk exhaustion (`ulimit -c 0`, bounded logs, watermarks); `ulimit -n` (`EMFILE`) and OOM worker step-down preserving logical slot IDs.
- **H. Hour 24 closing, boundary & billing release (`NF-28`–`NF-30`):** Clean `STOP_NEW_GAMES` at `23:00` + final partial piece seal + `A26` 3-class report (`A11`); `131`-round boundary policy (`-2,319,168` rows short of `2B`, `114510Z`); separating engine-stopped from provider billing release (`A11`).
- **I. Non-interactive SSH, observability, matches, codecs & packaging (`NF-31`–`NF-35`):** Pinned `known_hosts` + `BatchMode=yes` (zero interactive prompt hangs) & zero secrets in repo; home-owned hourly status line reporting trailing rolling rate and explicitly flagging `SERVER_UNREACHABLE`; `A16` match-pair durability if spare hours exist; **codec availability check on BOTH hosts (`NF-34`: F-5 prohibits installing anything on the PC — verify Python stdlib codec vs `zstd` before choosing!)**; clean `source/` outbound package verification (`NF-35`).
