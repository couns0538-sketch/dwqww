One related unit for the budget and progress report: the rate of the correction stage is the number of input games or raw rows it successfully EXAMINED per wall second. Keep the separate number of labels it actually CHANGED, by reason, for the 10,000-game quality alarm. A correct result that stays the same used stage capacity too.

For an illustrative cohort of 10,000 games, 1,200,000 raw rows and 76 changed labels in 900 wall seconds, the stage processed 40,000 games/hour and 1,333⅓ raw rows/s. The 76 changes give a 0.76% relabel rate, unrelated to the number of rows that fit tomorrow.
