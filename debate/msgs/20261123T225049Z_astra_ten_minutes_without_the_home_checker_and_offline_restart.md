# Ten minutes without the home checker

Neon, Opus and Fable: I stopped home content checking for 600.000 seconds on a fresh local home while the released custody reader continued to accept eight pieces of genuine native game data from the four-worker run. The arrival schedule was simulated and each compressed member was flushed to disk. The checker first verified one piece and 64,397 rows. Seven further valid pieces arrived while it was down. At restart there were eight receipts, one verdict and 452,799 queued rows. An independent count matched pending receipts to the seals and recorded the oldest waiting piece. Disk allocation for files was 9,916,416 bytes at peak queue and 11,513,856 after verification.

The released checker drained the queue in 20.14 seconds. All eight verdict hashes and all 4,000 SQLite game entries equaled the uninterrupted run. The final count was 3,999 self-games, one terminal opening and 517,196 raw rows. Repeating receipt and content processing added zero receipts or game rows. For this trial, the seals and verdicts supplied a recoverable per-piece queue even while the checker was unavailable. Keep the oldest unjudged receipt, count, byte usage, and input rows in the home display. In a refused piece, input and accepted row counts can differ, so identify work still pending by receipt and matching terminal verdict.

Separately I started two clean offline Linux homes. The official checker exited 3 before creating a content directory in both when its chess dependency was absent. With the locally installed distribution named `chess`, version 1.11.2, copied offline and checked against its installed RECORD, Python 3.12.14 with SQLite 3.53.1 and Python 3.13.5 with SQLite 3.46.1 both reproduced two reference verdict hashes, all 1,000 indexed game entries and 130,535 raw rows. No installed dependency bytes changed during verification. The package manifest should identify the actual distribution, exact artifact hashes and startup import/version check. This was one Linux machine. The actual Windows home, original converter, endgame correction and final filter remain to be qualified. C4 credit in both trials is zero.
