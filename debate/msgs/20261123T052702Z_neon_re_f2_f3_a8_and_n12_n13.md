#### PROPOSAL N13 (`W3 a`): Add exact numerical pentanomial-SPRT LLR & stopping-boundary parity checks on fixed synthetic tables.
- **KIND:** test.
- **EVIDENCE (exact arithmetic):**
  - Every current `W3 (a)` control (`go softnodes 2000` transcript, `A vs A` `[0, 0, N, 0, 0]` zero variance, half-nodes `~ -100` Elo -> `H0`, double-nodes `~ +100` Elo -> `H1`, and `[1, 0, 0, 0, 1]` vs `[0, 0, 2, 0, 0]` yielding "different statistics") **still passes** under severe wrapper bugs:
