# Astra’s independent server-day failure list

Frozen before opening either peer’s failure list. This is input to Fable’s setup plan. W5 in the shared plan, its A11/A14/A23/A26/N12/N16/N17 requirements, and the PC draft F-1 to F-7 form the baseline. The owner’s new-branch order sets memory checkpoints about every ten minutes and owner summaries every two hours. This list was written independently before the pause and carried here after the ordered new-branch reading, before opening the other seats’ lists.

| What can go wrong | How the scripts notice | Automatic reaction and rehearsal that must fail when the safeguard is removed |
|---|---|---|
| The lease starts earlier than the launcher, the provider changes its expiry, the wall clock jumps or a reboot resets uptime. | Record the provider’s actual start/absolute expiry in UTC plus host boot identity. Derive remaining paid time on each restart; use a monotonic clock for elapsed work within a boot. An expired or unverified lease is a closed admission gate. | Stop new assignments at the earlier of hour 23 or the deadline minus the measured closing reserve. A restart 22h55 into a lease has five production minutes left at most. Plant local clock skew and a reboot during close; neither buys another production shift or erases a receipt. |
| The offered CPU variant cannot execute, has fewer usable workers than advertised, or the home disk/physical volume is too small. | Probe usable ISA, affinity/quota, available RAM, per-volume free bytes, compression, spool and receiver throughput under actual concurrency. Read the owner’s disk floors separately for each volume. | Select an approved supported build and rerun its pins. Reduce concurrency only if the new measured pilot still succeeds. Pause before disk floors or lease reserve would be violated. Plant a lower CPU limit, an unavailable volume and two paths on the same physical volume. |
| A modified dependency or old script is launched despite three approvals for another set of bytes. | A pre-approved launcher checks the frozen path/digest manifest, three distinct real seat approvals per digest, the actual invoked file and its imported helpers/config/net/book. Check installed copies after extraction, including bootstrap, watcher, restart and close paths. | Stop before starting the affected work. A changed line, missing helper, duplicate signature or unlisted executable must fail. Pin the independent manifest/approval identity outside the package being verified. Store identity on every log and receipt. |
| A valid-looking build uses the wrong profile, options, evaluator, reset or opening. | Compare full options actually sent and engine replies, active evaluator, ISA and pins. Validate ordered batch through real persistent launcher/packer/home receiver, replay six historical games plus N15 guard fixture and A23 actual position command. | Stop production on a mismatch; retain first differing game, row, field and bytes. Plant missing ucinewgame, wrong Hash, altered guard, exchanged same-FEN histories, unavailable profile and wrong net. |
| The allocator or worker dies while a reservation is durable but a result is incomplete; a replacement reuses a process-local sequence. | Run/producer ID, logical slot, game, immutable opening reservation and row index travel through each stage. The home checks complete end record for every game, including zero-row games. Shared storage identifies an unfinished reservation. | Replay that logical ID with its original opening under the same frozen producer, or quarantine an irreproducible conflict. Exercise death before dispatch, during the game and after sealing. Move the lease of the logical slot to another executor and wake the old one late; only the verified canonical result may count. |
| A file is visible before closure, a transfer resumes from a wrong prefix, or an acknowledgment is lost. | Distinguish private temporary pieces, immutable compressed pieces, validated local receipt and released round. Check exact packed length, SHA-256, predecessor, slot manifest and run ID. | Retry a missing/corrupt piece from the immutable source. An identical retry gets its old receipt; no server removal before durable home ACK. Kill the receiver before durable storage, after durable storage but before ACK, and during temporary output. Recover the same set of credits. |
| Every game ID appears but a predecessor, zero-row game or lower-ordinal competing record remains outstanding. | Check fixed round membership for every logical slot, authenticated seal and all predecessor pieces. Rebuild the canonical sequence by manifest slot, game and row; compare output digest to a clean reference. | Withhold the round until verified; replay conflicting data independently or quarantine. Deliver +19/+42 witness in reversed order and recut across files. Include a late identical retry after release and changed payload after release. Verify exactly one row value and one round release. |
| The home system credits downloaded/raw rows as kept or trains on a differently rescored game. | Separate compressed arrival, verified raw game, corrected outcome, filtered retained row and durable released-range counts. Keep native outcome and ending beside the correction and its reason. On a frozen PC round compare the actual retained rows/labels in canonical order. | Withhold training credit until the real home rescorer and filter complete. Plant a failed table probe, side-to-move result sign swap, duplicate collision and hidden table directory. Keep quarantined data packed for retry and show its count. |
| A line or PC outage lasts two hours and backlog is mistaken for steady throughput; space is exhausted while unpacking. | Record oldest unacknowledged piece, backlog bytes and net drain rate at each stage. Forecast catch-up from measured receiver rate minus ongoing production. On each physical volume reserve simultaneous packed input, temporary output, correction/filter scratch and the largest training window. | Home pulls over its existing tools and resumes from receipts. Apply backpressure before headroom is exhausted. Keep packed canonical output and discard temporary text only after durable packed verification. Rehearse a two-hour-equivalent backlog, full disk and disconnect at final ACK. |
| The pilot is credited for staged or previously verified data, the same core-hour or pilot row is counted twice, or matches crowd out the 2-billion target. | Snapshot unique verified kept rows at both ends of a paid wall interval, with pilot IDs and backlog boundaries. Count only accepted increments in its elapsed time. Record completed match games and pairs, slots and separate elapsed time for each workload. | Admit matches only from independently measured surplus after correction/filtering and closing reserve; measure mixed throughput if proposing concurrent workloads. On restart recompute using unique committed rows and remaining lease time. Plant 200 duplicate receipts, a zero-release pilot, a slow home filter, an expired window, and a pilot that overlaps the schedule boundary. |
| Work straddles the production cutoff, the last range is only partly assigned, or a replay is silently allowed in the verification-only hour. | Stop issuing new games before measured worst-case drain. Log cutoff, last allowed start, manifest size for any intentionally shortened final range, and expected versus verified ID sets. Older unknown slots never become an intentional shortened range. | Seal available complete work and report separately complete verified, recoverable in transit and unrecoverable/missing. Rehearse an unfilled final piece, two-hour outage straddling the cutoff, lost final ACK and a permanently missing game. No fractional range is counted; protect the provider release deadline. |
| Two watchdogs launch simultaneous producers, an SSH/AI session ends, or the system reports a healthy PID while no verified work advances. | One durable run identity and fenced logical assignment. Monitor worker progress, most recent durable receipt, queue trend and time to disk floor separately. Surface stale progress even if process is alive. | Start or recover the correct services exactly once with bounded retry/backoff. Pause affected stage on persistent faults, preserve evidence and continue independently safe work. Rehearse detached launch, supervisor death, repeated starts and a permanently stalled home stage. |
| A machine outage, incomplete handoff or provider billing continues after shutdown. | Bind receipts to the lease/run identity. Compare home durable manifest to the exact expected set. Treat provider release evidence, not a successful local shutdown, as the end of billing. | Carry home all verified results. On a new host admit only after its own checks/pilot and with a new executor identity. Preserve missing counts and the owner's release action/record. Never auto-book a substitute or count inaccessible source bytes as safe. |

**Acceptance of the runbook.** The small rehearsal must pass through the real entry points, with an uninterrupted run as a reference and the deliberate failures above. Record exact component hashes, environment, expected/actual results and what Fable still needs to check on the PC. A test double can prove a transition in isolation. The booking gate depends on the real unattended producer-to-home rehearsal and the actual three-seat ledger.
