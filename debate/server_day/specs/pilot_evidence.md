# Collect a closed first-hour pilot at home

**Duty.** The existing budget calculator consumes a pilot report. Produce the evidence that stands behind that input. Run the complete paid path at the intended worker width, after the machine, package, binary and six fixed-game checks pass. Before it begins, declare K whole production-equivalent rounds, at least one, fixed slot/range IDs, empty starting queues, intended home load, the time limit and the owner's fallback. Time from the start of the cohort's first game until home publishes durable C4 for all K. Record overlap with old work, retries and duplicates separately. A pilot that cannot close by the policy deadline is unqualified for the forecast.

**Inputs and outputs.** Bind the pilot cohort, input state, policy, immutable run header and control to the same run at both ends. Keep the identities of the schedule and package, timestamps and raw observations. Reusing a policy on a replacement machine does not transfer the old machine's pilot measurement. For the same whole cohort measure complete games/hour, raw rows/game, whole-round kept share, C1/C2/C3/C4 input throughput, packer/transfer rate and retry bytes. Convert each comparable stage capacity to kept rows using the same cohort and compare with unique C4 divided by total elapsed seconds. The lower end-to-end or stage capacity governs D4. Record games per minute during warmup and heat, full group's memory high-water mark, longest game, measured closing time, exclusive time still needed, physical volumes with both raw and wire sizes, entries and restart reserve. Emit the measured fields and hashes the budget tool requires. A single-worker extrapolation cannot qualify a new width.

**Known answers to check before implementation.**

- Over 1,200 s, exactly 3,000,000 distinctive kept rows from the declared cohort become durable. Exclude 27,000,000 carried-in rows and 200 repeat appearances. End-to-end rate is 2,500 kept rows/s. If an independently measured same-cohort stage can handle 2,300 kept rows/s, D4 receives 2,300, with the 2,500 measurement also shown.
- In 600 s finish 100 cohort games with a total of 20,000 raw rows. The completed round keeps 10,000. That is 600 games/hour, 200 raw rows/game, a share of 1/2 and 16⅔ durable kept rows/s. A different small range predicting 19,000 kept cannot replace that whole-round result. Stop a second run before durable C4 and it stays unqualified.
- With 80,000 s and 2 billion outstanding, needed rate is 25,000 kept rows/s. A correctly measured safe 20,000 supports a 1.6-billion scenario and a documented shortfall. Use the owner's declared under-target policy. An absent rate, disk bound or policy cannot quietly authorize production.
- With a 24-hour lease and a measured 90-minute close, production D is 22 h 30 min from lease start. If the longest game plus margin is 6 min, the last dispatch boundary is 22 h 24 min. Two hours already spent in exclusive work leave 20 h 30 min to D in this fixture. A restart cannot reset either bound.
