## A. Pre-Flight, Machine Qualification & Package Integrity (Hour 0:00–0:20)

| **NF-31** | **Interactive SSH prompt hangs unattended fetcher** (`yes/no` host-key prompt, passphrase prompt), wrong key permissions (`0644`), or credentials/provider IP leaked into git. | Preflight validates key permissions, dedicated `known_hosts` file pinned during first-hour setup, non-interactive `ssh -o BatchMode=yes -o StrictHostKeyChecking=yes` smoke test, and verifies no secret/IP file lies inside tracked repo paths. | `BatchMode=yes` fails fast instead of hanging indefinitely on any prompt; host-key mismatch immediately aborts transfer with `HOST_KEY_MISMATCH` (preventing silent MITM/wrong-host fetch). | Planted test with mismatched `known_hosts` entry and with passphrase-protected key -> fetcher fails fast within `ConnectTimeout` (`< 15s`) with explicit error, never hangs. |
| **NF-32** | **Hourly status/progress reporter fails silently, hides a mid-day slowdown via cumulative averaging, or dies when the server dies.** | Home watchdog owns the hourly status line and logs BOTH trailing 1h rolling verified rate AND cumulative verified rate, `needed_rate`, worker count, sealed-vs-fetched backlog, quarantine counts, `A14` rescore & failed-probe counts, and free disk above floors on BOTH machines. | If server stops responding or heartbeat ages `> 10 min`, home watchdog STILL writes the hourly status line explicitly flagging `SERVER_UNREACHABLE (X min)` or `STALE_HEARTBEAT` so the owner sees the fault immediately on return. | Stop server process mid-rehearsal -> home status log continues ticking on schedule and explicitly reports `SERVER_UNREACHABLE` with exact duration and last verified count. |
| **NF-33** | **Optional server-day match runner loses or double-counts game pairs on restart/preemption** (`A16`), or mismatches net/option sets between match arms. | Match runner assigns durable `(match_id, pair_id, color)` IDs, verifies both arms' `NNUEArchFile` SHA-256 + `N15`/`N17` startup checks, and reconciles completed pair receipts on resume. | Preemption (when self-play needs cores back per `NF-10`) or worker restart resumes strictly from unfinished pair IDs and credits each `(match_id, pair_id, color)` exactly once; incomplete single-color halves are never counted as a completed pair. | Kill match runner mid-chunk and restart -> exact same completed pair count and W/D/L totals as uninterrupted run, zero duplicate pair IDs (`A16`). |
| **NF-34** | **Compression codec / tool unavailable on home PC or server** (F-5: *nothing may be installed on the PC* — e.g. server uses `zstd` when PC only has Python stdlib `zlib`/`gzip`/`lzma`). | Both server preflight AND home preflight run a round-trip compress + decompress + SHA-256 self-test using the manifest's declared codec (defaulting to a codec guaranteed present in standard Python on both Linux and Windows, e.g. `zlib`/`gzip`, unless PC confirms native availability of another codec). | Refuse startup if declared codec fails round-trip self-test on either host; never silently switch codecs or send uncompressed data. | Plant an unavailable codec name in manifest -> preflight fails immediately on both hosts with explicit missing-codec error. |
| **NF-35** | **Outbound package built from dirty/uncommitted `source/` or missing required assets** (headers, opening book, `LOOP_OPTIONS.txt`, `N12+N15` reference fixture, `A14` fixture). | Package builder checks clean `git status` on `source/`, records exact `git HEAD` SHA + `MANIFEST.sha256` of every archived file, and verifies archive extraction + complete manifest hash match on arrival before anything executes. | Package builder refuses to pack dirty `source/` unless explicitly flagged for a non-production dry run; server arrival check refuses extraction with any missing file or hash mismatch (`exit 2`). | Plant (a) modified file in package after archive creation; (b) omitted fixture file from tarball -> server arrival check refuses before compile. |
