# opus_oss_scout - open-source tools, libraries and data for Forge (2026-11-06)

Research and sandbox-trial job on grok-pc. Nothing here changes the engine, the gates, self-play or NNUE training.

| File | What |
|---|---|
| `STATUS.md` | Handoff: done / in progress / next step / resume commands / unproven claims (master copy: `C:\opus_5h\oss_scout\STATUS.md`) |
| `CATALOG.md` | Survey: every candidate with repo URL, licence, last activity, gain, fit, effort |
| `REPORT.md` | Ranked picks, measured trial results, next actions, owner suggestions, ideas-only (GPL/AGPL) section |
| `trials/<name>/` | Per trial: `CMDS.md` (exact commands), `RESULT.md`, `TUNING.md` (PC-specific ideas), `SHA256SUMS`, `logs/` |
| `tools/` | Own scripts used by the job (gate check, commit helper, analysis scripts) |

Big files (downloads, builds, data samples) stay in `C:\opus_5h\oss_scout\{dl,build,data}` and are not committed.
